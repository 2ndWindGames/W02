# 수중 표현 구현 기준 v0.1

최종 갱신: 2026-09-02  
범위: 현재 Unity 낚시 프로토타입의 외형적 수중 표현만 개선. 물고기 이동·상태 머신·낚시 규칙은 변경하지 않는다.

## 방향

**차분한 수중 관찰형 + 상호작용 순간만 캐주얼하게 튀는 스타일**을 기준으로 한다.

- 어두운 teal/navy 톤과 현재 어종별 색상 정체성을 유지한다.
- 외부 모델·외부 텍스처·AI 아트를 가져오지 않고, 교체 가능한 로컬 prototype substrate source와 절차 셰이더로 검증한다.
- 화면을 화려하게 만드는 것보다, 정지 화면에서도 “위에서 물속을 내려다본다”는 공간감을 우선한다.

## 현재 구조

이번 revision의 표현 런타임 경로는 다음과 같다.

`FishingV2Session` → `FishingV2UnderwaterCamera` → `FishingV2_UnderwaterSceneRT`
→ `WaterSurfaceV2` composite → `FishingV2Camera` → `OnGUI HUD`

layer 30의 underwater camera는 메인 카메라와 같은 직교 시점으로 다음을 한 장에 렌더한다.

- `UnderwaterBottomLayerV2`: 연속 substrate + 기존 water color/caustic receiver
- fish 메시와 World-Z projected shadow
- 현재 C 환경의 rock/vegetation placeholder
- bobber, ripple ring, catch flight

메인 카메라는 layer 30을 제외하고 `WaterSurfaceV2` composite 쿼드만 화면에 그린다. composite는
`_UnderwaterSceneTex`를 저주파 `OpticalDisplacement`로 한 번 샘플하고, 전체 RT에만 절제된
water absorption을 적용한다. `FishingV2Session.OnGUI`는 메인 화면 경로에 남으므로 HUD에는
이 굴절이 적용되지 않는다. 물고기 메시·행동·상태 머신은 기존 절차 메시와 gameplay 코드를
그대로 재사용한다.

## WaterSurfaceV2 레이어

`WaterSurfaceV2.shader`는 `_UnderwaterComposite` 값에 따라 두 역할을 가진다. `0`이면
underwater RT에 들어갈 연속 bottom/water/caustic layer를 렌더하고, `1`이면 메인 카메라에서
RT 전체를 샘플하는 최종 composite가 된다. 두 material은 같은 palette와 substrate slot을
공유하지만 surface refraction은 최종 composite에서 한 번만 적용한다.

### Base Water

`_DeepColor`와 `_ShallowColor`로 기존 어두운 수중 톤을 유지하고, 화면 세로 방향으로 완만한
깊이 그라데이션을 만든다.

### Continuous Bottom Layer

이번 패스의 주 대상은 장식용 patch가 아니라 화면 전체에 이어지는 underwater substrate다.
`BottomFloorValue`가 서로 다른 저주파 smooth value-noise를 macro/broad/middle 비율로 합성해
큰 모래·진흙·돌 명암 덩어리를 만들고, `BottomFloorGrain`은 약한 유기적 재질 breakup만
추가한다. 둘 다 UV 공간에 고정된 절차 필드이므로 caustic처럼 화면을 가로질러 흐르지 않는다.

바닥 색은 `BottomDarkColor`와 `BottomLightColor` 사이의 낮은 대비 범위로 제한한다. `BottomVisibility`
는 화면 전체에서 바닥이 이어져 있음을 유지하되, 중앙 `ClearZone`과 얕은 수심에서 더 높아지고
외곽 edge fog와 깊은 수심에서 낮아진다. 따라서 “텍스처가 붙어 있다”보다 “물 아래에 바닥이
있다”는 인지를 우선하며, 물고기와 lure보다 앞에 나오지 않도록 grain은 낮게 유지한다.

`UnderwaterBottomLayerV2`는 이 연속 substrate를 기존 water palette 및 floor caustic과 함께
underwater RT에 먼저 렌더한다. 기존 non-polygonal organic caustic의 shape language와 C 환경
오브젝트는 유지하고, 최종 composite가 RT 전체에 surface field를 적용한다.

### Organic Bottom Material

기존 `BottomFloorValue`가 바닥의 visible appearance를 단독으로 만들지 않도록 역할을 낮추고,
작은 로컬 source texture `BottomSubstrateOrganic.png`가 mud/olive/soft-stone 재질 identity를
담당하게 했다. 이 source는 256×256 tileable PNG이며, Editor generator가 저주파 sediment,
soft-stone core, dark mud pock을 deterministic하게 생성한다. 외부 다운로드 asset이나 PBR pack은
사용하지 않았다.

`WaterSurfaceV2.shader`는 pond-local UV에서 primary sample을 읽고, 같은 source를 0.47 rad
회전·1.73배 다른 scale·offset으로 한 번 더 읽는다. 두 샘플을 `BottomSecondarySampleStrength`
로 섞어 단일 tile의 반복감을 낮춘다. `BottomTextureContrast`와 `BottomTextureBlend`는 source를
물에 그대로 붙이지 않고, 현재 water palette와 procedural macro 사이에 제한된 범위로 섞는다.
texture sample에는 시간 기반 UV 이동이 없으며, `BottomFloorValue`의 시간 변화는 거의 정지한
material modulation으로만 사용한다.

### Water Optics / Surface Refraction

이번 revision의 중심은 개별 오브젝트를 같은 함수로 흔드는 것이 아니라, **underwater scene
전체를 한 장의 움직이는 수면으로 통과시키는 것**이다.

`FishingV2UnderwaterCamera`가 layer 30의 bottom/fish/shadow/환경을
`FishingV2_UnderwaterSceneRT`에 렌더한다. 메인 `WaterSurfaceV2` composite는 이 RT를
`OpticalDisplacement`로 한 번 샘플한다. 따라서 바닥 재질, 물고기 실루엣, World-Z 그림자,
rock/vegetation이 같은 저주파 surface deformation을 공유한다. 공통 field 구현은
`WaterOpticsField.hlsl`에 두고 Water/Fish shader가 함께 사용한다.

- `OpticalDisplacement`: 서로 다른 scale/speed의 두 연속 surface height field에서 gradient를 구해 만든 2축 refraction vector다. 현재 refraction coefficient는 `0.0035 UV`이며, 1024×474 Game View에서 대략 1–2px로 제한한다. 고주파 shimmer나 full-screen wobble는 사용하지 않는다.
- `OpticalConcentration`: 같은 height field의 curvature를 유한 차분으로 구해 floor caustic의 넓은 밝기 집중과 연결한다. filament는 낮은 breakup 비율로만 유지한다.
- `_OpticalTime`: 플레이 빌드에서는 `Time.unscaledTime`, Editor 캡처에서는 `EditorApplication.timeSinceStartup`을 사용해 simulation pause 중에도 surface/caustic만 움직일 수 있다.
- `WaterOpticsSurfaceHighlight`: 동일 gradient에서 완만한 surface normal을 만들고, key/fill light lobe를 합성해 above-water looking-down 수면 하이라이트를 만든다. 이 응답은 UV displacement가 아니라 조명 신호이며, `SurfaceRippleStrength 0.85`의 낮은 additive/multiplicative 범위로 제한한다.
- composite absorption/highlight: RT 전체에만 edge/depth tint와 약한 shared surface light를 적용해 fish와 shadow를 같은 수중 매질에 묶는다. UI는 이 레이어 밖에 남는다.
- UI: `OnGUI` 경로에 남아 RenderTexture sampling과 무관하게 안정적으로 그린다.

simulation X/Y, fish state, lure 판정 위치는 optical pass에서 읽기만 한다. `FishAgentV2`는
직접 optical XY offset을 더하지 않고 월드 위치와 World-Z만 렌더하며, 그림자도
`ShadowBottomZ`와 `LightDirection`으로 계산한 투영점만 유지한다. `BobberV2` 역시 월드 위치와
ripple 상태만 관리한다. 이전 `FishingV2WaterOptics` C# scalar helper와 fish/shadow/bobber
optical strength 필드는 기존 serialized/test 호환을 위해 남아 있지만, coherent RT 런타임 경로에서는
사용하지 않는다.

### Water Color Integration

바닥을 밝힌 뒤 water color가 다시 하나의 dark teal로 뭉치지 않도록 broad palette를 분리했다.

- `ClearWaterColor`: Clear Observation Zone에서 clean cyan-teal로 이동
- `DeepWaterColor`: 외곽과 깊은 영역에서 blue/navy로 이동
- `BottomBleedColor`: substrate의 muted mud/olive가 최종 물색에 아주 약하게 스며드는 tint
- `ClearColorStrength`, `DepthColorStrength`, `BottomColorBleed`: 각 영향량

색 통합은 hard radial band 대신 기존 noisy `clearZone`, `edgeFog`, 화면 depth field를 함께
사용한다. substrate를 먼저 합성한 뒤 clear/deep water palette를 다시 통과시키므로, 바닥이
보이는 영역도 갈색 물로 변하지 않고 cyan-teal → dark teal → blue/navy 관계를 유지한다.

### Projected Floor Caustic

기존 organic caustic은 장식용 foreground pattern이 아니라 바닥에 맺히는 refracted light로
재정의했다. `UnderwaterBottomLayerV2`가 먼저 substrate와 floor light를 렌더하고, 그 결과가
fish/shadow/환경과 함께 RT에 들어간다. 최종 composite는 RT 전체를 같은 `opticalUV`로 샘플하므로
caustic과 foreground가 서로 다른 XY 보정을 받지 않는다. `floorReceiver`는 바닥이 보이는
영역에서만 상대적으로 강해지게 하고, `OpticalConcentration`은 같은 surface field의 밝기
집중을 약하게 반영한다. broad floor-light energy를 bottom base 색에 아주 약하게 곱해 실제
밝기 변화로 읽히게 하며, filament breakup 비율은 낮춰 화면 앞에 선무늬가 떠 있는 인상을
줄인다. edge/deep fog에서는 약해진다.

### Large Slow Caustic

저주파 value noise와 surface curvature를 함께 사용해 화면 전체의 floor-light energy를
느리게 움직인다. 이번 visible-surface pass에서는 같은 surface normal response도 약하게
참조해, 수면 하이라이트와 바닥 transmitted light가 서로 무관한 noise처럼 분리되지 않게
했다. bottom base에 대략 5–8% 수준의 넓은 밝기 변화를 만들고, 단독 blob처럼 보이지 않도록
substrate palette 안에서만 제한한다.

### Mid Caustic

서로 다른 주파수와 scroll 방향의 smooth value-noise 필드를 약하게 domain-warp한 뒤,
필드 간의 일치 구간을 breakup으로 추출한다. 넓은 smooth carrier가 주성분이고 filament는
낮은 비율의 재질 breakup으로만 사용한다. 이 방식으로 큰 polygon cell·cracked-glass·net
패턴을 직접 그리지 않으면서도 빛이 불규칙하게 합쳐지고 갈라지는 감각을 남긴다.
`opticalUV`와 `floorReceiver`를 거친 결과는 bottom receiver에 먼저 맺히고 최종 RT와 함께
굴절되므로, 화면 앞에 선무늬가 떠 있는 인상을 줄인다.

### Surface Micro Movement

고주파 sine 조합은 아주 낮은 강도로만 합성한다. 화면의 정지를 막는 역할이며, 직접적인
장식으로 인식될 정도로 올리지 않는다.

### Clear Observation Zone / Edge Fog

중앙은 단순한 밝은 원이 아니다. 중앙에서 채도를 조금 낮추고 대비와 디테일을 약간 높이며,
외곽에서는 청록 흡수 계수와 fog를 높인다. 반경에는 약한 유기적 노이즈를 섞어 노골적인
원형 vignette가 되지 않게 한다.

## Fish depth / light

`FishSpeciesConfig.VisualDepth`는 `0 = surface`, `1 = bottom`의 정규화 값이다.

현재 기본 범위:

| 어종 | VisualDepth |
|---|---:|
| 멸치 | 0.08–0.30 |
| 연어 | 0.20–0.58 |
| 만새기 | 0.36–0.68 |
| 오징어 | 0.28–0.60 |
| 참치 | 0.58–0.86 |

`FishAgentV2`는 이 값을 실제 `transform.position.z`로 변환한다. X/Y 행동 계산은 건드리지
않는다. `FishSurfaceV2.shader`는 동일한 값을 받아 다음을 절제된 범위로 조절한다.

- 깊어질수록 blue/teal tint 증가
- 채도와 밝기 소폭 감소
- 대비 소폭 증가
- 얕은 개체에만 약한 top light
- 최종 composite의 shared water absorption을 함께 받음
- shallow surface light에 최대 ±6% 이내로 반응
- 높은 점수/대형 개체에만 아주 약한 local contrast

광원 방향은 `LightDirection = (-0.36, 0.58, 0.73)`로 통일한다. 강한 bloom, outline,
rarity aura는 사용하지 않는다. fish material 자체에는 optical transform noise를 넣지 않고,
공통 height/curvature light에 shallow weight를 곱한 약 3–6% 이내의 value modulation만 적용한다.

## Shadow

그림자는 고정된 화면 X/Y 오프셋이 아니라 다음 관계로 계산한다.

`fish world position + light direction + ShadowBottomZ → projected shadow`

- 얕은 fish: 바닥까지 거리가 크므로 shadow offset이 크고, scale/halo가 크며, opacity가 낮다.
- 깊은 fish: 바닥에 가까우므로 shadow offset이 작고, scale/halo가 작으며, opacity가 높다.
- 두 번째 저알파 `ShadowSoft` 복사본으로 외곽 penumbra를 만든다.
- 부모 fish scale이 달라도 바닥 Z가 흔들리지 않도록 `InverseTransformVector`로 local offset을 계산한다.
- shallow shadow는 `ShadowMaxScale * 1.10`, opacity는 `ShadowMinOpacity * 0.16`, softness는 최소 `0.74`로 시작한다.
- deep shadow는 `ShadowMinScale * 0.94`, opacity는 `ShadowMaxOpacity * 0.42`, softness는 `0.32`까지 조여진다. 깊은 그림자도 opaque fish copy가 되지 않도록 제한한다.
- projected shadow는 layer 30 underwater RT에 fish와 함께 렌더된 뒤, 최종 composite에서
  fish와 동일한 surface refraction/absorption을 받는다. 그림자 자체에는 별도 XY noise나
  optical alpha modulation을 더하지 않는다.

## Bobber ring / physical ripple

gold interaction ring은 `BobberRing`으로 유지하고, 물리적인 물결은 `BobberPhysicalRipple`이라는
별도 low-alpha `LineRenderer`로 분리한다. 두 renderer는 `WaterRippleV2.shader`의 투명
Unlit material을 사용해 vertex alpha가 보존된다. ripple은 InWater 상태에서만 보이며,
자체적인 screen-space noise를 추가하지 않고 underwater RT에 들어간 뒤 gold ring/fish/shadow와
같은 최종 surface refraction을 받는다. 현재 physical ripple 기준은 width `0.026 world unit`,
base radius `0.68 world unit`, pulse scale `0.74–1.16`, alpha `0.36–0.54`이다.

## Inspector 튜닝

`FishingV2Session.PresentationOverrides.Enabled`를 켜면 다음 값을 조절할 수 있다.

- `ClearZoneStrength`, `ClearZoneRadius`
- `ClearColorStrength`, `DepthColorStrength`, `BottomColorBleed`
- `OpticalDistortionStrength`, `OpticalDistortionScale`, `OpticalDistortionSpeed`, `OpticalCausticFloorBias`
- `FishOpticalStrength`, `ShadowOpticalStrength`, `BobberOpticalStrength` (legacy serialized compatibility; RT path에서는 비활성)
- `BottomVisibility`, `BottomGrainStrength`, `BottomVariationScale`
- `BottomTextureScale`, `BottomTextureBlend`, `BottomTextureContrast`, `BottomSecondarySampleStrength`
- `LargeCausticStrength`, `LargeCausticScale`, `LargeCausticSpeed`
- `MidCausticStrength`, `MidCausticScale`, `MidCausticSpeed`
- `MicroSurfaceStrength`
- shader-only `SurfaceRippleColor`, `SurfaceRippleStrength` (현재 `0.040/0.160/0.180`, `0.85`)
- `EdgeFogStrength`, `EdgeFogRadius`
- `FishDepthTintStrength`, `FishDepthDesaturation`, `FishDepthBrightnessDrop`, `FishDepthContrast`
- `ShadowDepthInfluence`, `ShadowSoftness`

A 프리셋의 이번 Organic Bottom + Water Color 기준값은 `BottomVisibility 0.72`,
`BottomGrainStrength 0.06`, `BottomVariationScale 1.12`, `BottomTextureScale 1.55`,
`BottomTextureBlend 0.66`, `BottomTextureContrast 1.08`, `BottomSecondarySampleStrength 0.42`다.
물색 통합은 `ClearColorStrength 0.52`, `DepthColorStrength 0.52`, `BottomColorBleed 0.09`다.
Water Optics 기준값은 `OpticalDistortionStrength 0.68`, `OpticalDistortionScale 1.08`,
`OpticalDistortionSpeed 0.18`, `OpticalCausticFloorBias 0.78`다. 이번 pass에서도
global refraction strength/scale/speed는 늘리지 않았다. 이전
`FishOpticalStrength 0.16`, `ShadowOpticalStrength 0.48`, `BobberOpticalStrength 0.34` 값은
serialized compatibility만 유지하고, fish/shadow/bobber에 직접 적용하지 않는다. A caustic balance는
`Large 0.68 / Mid 0.36 / Micro 0.14`다. 1024×474 현재 Game View에서 refraction은 약 1–2px
범위로 제한했고, floor-light는 broad curvature/normal receiver에 5–8% 수준으로 반응한다.
Surface highlight는 같은 field를 사용하지만 scene distortion을 추가하지 않는다. 이전
1024×517 조건은 현재 `manage_camera`가 width/height override를 지원하지 않아 재현하지 않았다.
바닥 색상은 물고기 실루엣보다 앞서지 않는 muted mud/olive/stone 범위로 두고, B 프리셋은
같은 구조에서 조금 더 밝고 강한 값을 사용한다.

A/B 프리셋은 `FishingV2/Presentation` 메뉴에서 선택한다. 선택 변경은 런타임 메시와
Material이 생성되는 시점에 반영되므로 Play Mode를 재시작한다. 기본 씬은 A로 유지한다.

## 검증 기록

- Top-down 0°: A/B 모두 물 Quad, 눈 원반, fish depth가 정상 렌더됨.
