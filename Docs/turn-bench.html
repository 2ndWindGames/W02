접근 방식

최소 선회 반경0.55
근접 선회 보정0.40

몸길이 배수입니다. 선회율을 ω = 속도 / 반경 으로 뽑기 때문에 느린 물고기도 제자리에서 돌지 않습니다. 0.05 로 내리면 예전처럼 팽이가 됩니다.
근접 보정은 목표 코앞에서만 반경을 조입니다(기획서 §11).
속도 적합을 끄면 가까운 찌에서 소용돌이가 돌아옵니다 — 특히 학공치. 선회 반경은 v/ω 라 빠른 물고기일수록 크게 돕니다.
