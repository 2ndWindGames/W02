## ⚡ 빠른 시작 — 메뉴 3번 누르면 돌아갑니다

에디터 자동화 스크립트(`Editor/FishingSetupWizard.cs`)가 지겨운 부분을 대신합니다.

```
1) 파일 전체를 Assets/Fishing/ 아래에 복사 → 컴파일 통과 확인
2) 메뉴  Fishing > 스프라이트 임포트 설정 적용
3) 메뉴  Fishing > 1. 어종 · 낚시터 애셋 생성      (§7 수치 전부 자동 입력)
4) 메뉴  Fishing > 2. 프리팹 생성 (Fish · Bobber)
5) 빈 씬에서  Fishing > 3. 현재 씬에 세션 구성
6) 재생 → 수면을 클릭해 찌를 던진다
```

**플레이스홀더 스프라이트가 이미 들어 있습니다** (`Art/Placeholder/`).
dorsal view, 머리 오른쪽, 위아래 여백 40% — 셰이더 요건을 맞춰 만든 것이라
아트를 기다리지 않고 바로 1~4단계 검증이 됩니다. 나중에 실제 스프라이트로 교체하면 됩니다.

**이 세 메뉴가 만드는 것**

| 메뉴 | 결과물 |

| 3 | 씬에 FishingSession · Bobber · CatchFlight · Rock 3개 · 바구니 슬롯 4개, 카메라 세팅 |

## 1단계 — 프로젝트

- **URP 2D** 로 생성 (Shader Graph를 안 쓰더라도 셰이더가 URP 전제로 작성됨)
- 카메라: Orthographic, **Size 4.5** (수면 높이 9유닛의 절반)
- 해상도: 가로 16:9 기준. 방향은 아직 미결정이라 나중에 바꿔도 코어는 안 바뀜

## 2단계 — 셰이더 먼저 확인 ★

**기획서 §12-2에서 이걸 2순위로 둔 이유**: 이 프로젝트에서 유일하게 프로토타입으로 검증 안 된 부분입니다.
잘못되면 아트 규격(여백)까지 되돌아가야 하니 **첫날에 확인하세요.**

1. `FishWave.shader` 로 머티리얼 생성
2. 아무 물고기 스프라이트나 넣고 SpriteRenderer에 적용
3. `_Amp` 를 0.12 근처, `_Freq` 5 정도로 두고 재생

**확인할 것**
- 꼬리가 흔들리는가 (머리는 거의 안 움직여야 정상)
- **꼬리가 스프라이트 경계에서 잘리지 않는가** ← 잘리면 여백 부족. 아트 가이드 §3-7 참조
- 물고기 여러 마리를 배치했을 때 **박자가 제각각인가** (월드 위치를 위상 시드로 쓰므로 자동)

**스프라이트 임포트 설정**
- Packing Tag **비울 것** (아틀라스에 들어가면 UV가 밖으로 나갔을 때 옆 스프라이트를 샘플함)
- Mesh Type: Full Rect
- Pixels Per Unit: 스프라이트 몸길이가 `FishSpeciesSO.bodyLength` 유닛이 되도록 맞출 것

## 3단계 — 프리팹

**Fish 프리팹**
```
Fish (Fish, FishView)
├─ Body    (SpriteRenderer, FishWave 머티리얼)   → FishView._body
├─ TailPivot                                     → FishView._tailPivot  (대물만)
│   └─ Tail (SpriteRenderer)                     → FishView._tail
└─ (Shadow 는 별도 오브젝트로 두거나 자식으로)    → FishView._shadow
```
- Shadow는 **자식으로** 둡니다. 회전·스케일을 그대로 상속받아야 실루엣이 맞습니다.
  위치만 `FishView` 가 월드 좌표로 따로 잡습니다(수면에 남아야 하므로) — `localScale` 은 건드리지 마세요.
- Sorting Order: 그림자(5) < 몸통(10) < 꼬리(9는 몸통 아래) — 자동 생성이 이렇게 잡아둡니다

**Bobber 프리팹**: 스프라이트 하나 + `Bobber` 컴포넌트, `_visual` 에 스프라이트 Transform 연결

## 5단계 — 씬

```
FishingSession (FishingSession)
  ├─ _spot          → 만든 Spot 에셋
  ├─ _bobber        → Bobber 프리팹 인스턴스
  ├─ _fishPrefab    → Fish 프리팹
  ├─ _fishRoot      → 빈 오브젝트
  ├─ _catchFlight   → CatchFlight 오브젝트
```

`CatchFlight` 는 `_flyerPrefab`(SpriteRenderer 하나), `_shadowPrefab`, `_basketSlots`(바구니 칸 Transform 4개) 연결.

## 검증 순서 (기획서 §12-2)

1. **플레이스홀더 도형으로** 4종 궤도가 각각 구분되어 보이는가
2. **셰이더** — 꼬리가 안 잘리고 박자가 제각각인가
3. 찌 던지고 **손 놓고 90초** — 물고기가 몰려오고 자동으로 잡히는가
4. 획득 연출 — 솟아올라 바구니로 가는가
5. 실제 스프라이트 교체 → 가로 100px에서 4종이 구분되는가
