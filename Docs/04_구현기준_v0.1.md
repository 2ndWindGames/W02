# 낚시 게임 구현 기준 v0.1

> 이 문서는 기존 문서를 덮어쓰지 않고, v0.3 코드·v0.4 기획·v0.5/v0.6 벤치 변경이 섞인 상태에서
> Unity 구현을 시작하기 위한 기준을 고정한다.

## 1. 이번 구현의 기준

- 엔진: Unity URP 3D
- 카메라: Orthographic, 수직 탑다운
- 수면: 16 × 9 유닛, 고정 화면, 가로 16:9로 시작
- 어종: 멸치 · 연어 · 만새기 · 오징어 · 참치 5종
- 주 리소스: 절차 생성 3D 메시 + 정점 컬러 + 정점 셰이더
- 2D 스프라이트: 3D 성능 문제가 확인될 때 사용하는 fallback
- 동시 물고기: 약 30~50마리까지 MonoBehaviour/Update로 구현

## 3. 게임플레이 기준

- 필수 조작은 찌 배치 하나다.
- 입질은 자동 회수가 기본이고, 탭은 즉시 회수 선택지다.
- 재착수하면 기존 `Notice`/`Interested`를 거리와 무관하게 종료하고 큰 놀람을 적용한다.
- 물린 순간에는 주변을 주목시키기만 하고, 실제 흩어짐은 채는 순간에만 발생한다.
- `Interested`는 여러 개체가 동시에 가능하지만 `Bite`는 한 개체만 가능하다.
- Bite 도착 지점이 차 있으면 대기하지 않고 3초 쿨다운 후 Roam으로 돌아간다.
- 획득은 끌어올림 0.30초 + 비행 0.55초 후 바구니 도착 시점에 집계한다.
- 연어 1, 멸치 2, 오징어 5, 참치 30을 고정 기준으로 사용한다.
- 만새기 점수와 일부 행동 수치는 기획서에 아직 확정되지 않았으므로 첫 수직 슬라이스에서는 시각·이동을 우선 검증하고 밸런스 표에 별도 표시한다.

## 4. 이동 기준

- `Lane`, `Loop`는 파라미터 기반 경로다.
- `Hover-Dash`는 부유·대시 상태를 보유하는 적분형 에이전트다.
- `School`은 PathType이 아니라 리더 참조를 가진 개체 변형자다.
- 물고기는 머리 방향으로만 전진한다. 위치 보간과 회전 보간을 분리하지 않는다.
- 선회율은 직접 튜닝하지 않고 `omega = speed / (minTurnRadius * bodyLength)`로 산출한 뒤 종별 상한을 적용한다.
- 목표 근처에서는 `CloseTurnBoost`, 빠른 접근에서는 `SpeedFitK`를 함께 적용한다.
- 경로 재진입 시 현재 위치가 새 경로 위에 오도록 `anchor`를 역산한다.
- 회피는 경로 함수가 아니라 2단 저역통과 오프셋으로 얹고, 앞쪽만 검사하며 같은 무리는 제외한다.
- 첫 프레임과 랩 프레임의 `dt`, 위치 차분, 속도, 정점 파라미터에는 NaN·순간이동 안전망을 둔다.

## 5. 렌더 기준

- 메시 앞 방향은 +X다.
- 프로덕션 메시 기본 해상도는 `RINGS=40`, `SEG=24`다. 벤치의 낮은 해상도는 실행 검증용으로 본다.
- 텍스처·본·애니메이션 클립은 사용하지 않는다.
- 정점 채널은 `UV0=(aU,aSeed)`, `UV1=(aRip,0)`으로 유지한다.
- 공용 셰이더는 `uAmp`, `uPhase`, `uTurn`, `uLen`, `uLag`, `uExp`, `uHinge`, `uSpread`, `uJet`, `uRoll`, `uRip`, `uRipW`, `uRipF`, `uTime`, `uDrift`, `uTurnLag`, `uArcBody`, `uArmSwing`, `uArmTuck`, `uPivot` 계약을 따른다.
- 물고기와 그림자는 동일 메시를 쓰되, 그림자는 수면에 납작하게 눕히고 별도 오프셋·알파를 적용한다.
- 오징어 외투막은 강체에 가깝게 유지하고 다리와 지느러미만 시간·선회·관성에 반응시킨다.

## 6. 현재 해소되지 않은 값

아래 값은 구현 중 임의로 섞지 않고 기준을 하나로 고정한다.

| 항목 | 서로 다른 값 | 현재 처리 |
|---|---|---|
| 멸치 사행 주기 | 기획 요약 6.8s / 최신 turn-bench 5.8s / 구버전 bite-bench 3.4s | 첫 이동 검증은 turn-bench 5.8s를 사용하고, 밸런스 확정 시 기획서를 갱신한다 |
| 만새기 점수 | 최신 어종에는 포함되지만 점수 표가 없음 | 첫 수직 슬라이스에서는 임시 3점으로 표시하고 밸런스 확정 전 교체 가능하게 둔다 |
| 세부 지느러미 높이 | `fishgen.py`와 turn-bench에 일부 상이 | 메시 생성은 `fishgen.py`, 벤치는 움직임·가독성 기준으로 사용한다 |

## 7. 구현 순서

1. Unity 프로젝트가 없는 현재 상태에서 버전 독립적인 C# 코어와 메시 빌더를 작성한다.
2. 새 URP 3D 프로젝트에 가져올 수 있는 데이터·런타임·셰이더·에디터 스크립트를 분리한다.
3. 수면·5종 메시·Lane/Loop/Hover-Dash·School을 플레이스홀더 없이 먼저 재생한다.
4. 찌·놀람·유인·관심·입질·자동 회수·획득 비행을 연결한다.
5. 실제 Unity Editor가 설치되면 컴파일, 에디터 메뉴, 플레이 모드, 30초/90초 관찰을 순서대로 검증한다.
